# PromptHub Dashboard

A responsive, premium dark dashboard for an AI prompt management platform.

## Stack

- React 19 and TypeScript
- Vite
- Tailwind CSS 4
- shadcn-style Radix primitives
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Build and validate:

```bash
npm run lint
npm run build
```

## Structure

```text
app/
├── components/
│   ├── dashboard/
│   ├── layout/
│   └── ui/
├── data/
├── hooks/
├── lib/
├── pages/
├── styles/
└── types/
```

All content is backed by local mock data. There are no API or backend calls.
